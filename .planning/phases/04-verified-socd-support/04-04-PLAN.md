<objective>
Assert at worker startup that the pinned tree can host the curated module, and earn `mode/m256wh`
its place in the registry with a real compile of both policies in the isolated image.

Purpose: D-04 closes the one prerequisite nothing checks today — the registry declares a minimum
community-module hook API version and nothing verifies the pinned tree offers it. D-06 makes the
ARM/STM32 board compile-verified before it is flashed, which is the precondition the hardware run
(plan 05) depends on, and is also the first time the project has compiled anything that is not AVR.

Output: one new key in the existing verify-env checks dictionary, a startup path that supplies the
registry's declared minimum, a `mode/m256wh` compile fixture, and a registry record earned by a real
matrix run.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → container argument vector | Values supplied by application code become docker and entrypoint arguments |
| pinned tree → curated module | The module compiles against hooks the tree must actually provide |
| compile evidence → registry claim | A registry record is a claim the product makes to users |
| build output → collected artifact | Exactly one file at one predetermined path may be accepted |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-14 | Tampering | module hook API mismatch between registry and pinned tree | high | mitigate | New `module_hook_api_version_ok` key in the existing verify-env checks dictionary, supplied from the registry at worker startup; the worker refuses to start when it fails (D-04) |
| T-04-15 | Spoofing | a registry claim without a compile behind it | high | mitigate | The registry record for `mode/m256wh` is added only after four green builds, and the matrix fails loudly if any compile-verified record lacks a fixture |
| T-04-16 | Tampering | the new minimum-version argument | medium | mitigate | The version string is shape-validated (three dot-separated non-negative integers) before it enters the argument vector, and the entrypoint passes arguments through as a vector that is never re-parsed by a shell (claude.md rule 4) |
| T-04-17 | Tampering | ARM artifact collection | medium | mitigate | The accepted-file rule stays as it is: one predetermined path, a single match, an accepted extension, a size cap. A naming mismatch must be diagnosed and fixed at the derivation, never by widening acceptance |
| T-04-18 | Denial of Service | four real compiles in the isolated image | low | accept | The matrix is an operator-run command, not a user-reachable path; per-build resource and wall-clock caps from Phase 3 still apply |
